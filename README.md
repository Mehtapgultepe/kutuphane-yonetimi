# Kütüphane Yönetimi

İleri Nesne Tabanlı Programlama final projesi. Java 17, Maven ve JUnit 5 kullanır. Kod yalnızca birim testleriyle çalışır.

## Eclipse'te açma
File → Import → Maven → Existing Maven Projects. Klasörü seç ve Finish'e tıkla.

## Testleri çalıştırma
`src/test/java` klasörüne sağ tıkla → Run As → JUnit Test.
